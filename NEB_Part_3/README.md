# NEB Trajectory Analysis & Visualization Script

## Overview
This Python script serves as an automated post-processing toolkit for Nudged Elastic Band (NEB) calculations. It is designed to extract, visualize, and analyze the optimization trajectory of a Minimum Energy Path (MEP). By processing the complete `.traj` history, the script generates 3D atomic structure snapshots, plots energy surface profiles, tracks macroscopic convergence, and outputs a refined multi-frame XYZ file for downstream animation.

## Details of the Computation
The script performs the following core background operations:
- **Trajectory Slicing**: Loads the complete NEB optimization trajectory (`S1_NEB_Full_Path.traj`) and segments it into distinct macroscopic optimization steps based on the defined number of images (`n_images = 32`).
- **Energy Normalization**: Computes relative potential energies by aligning the starting image of each macro step to a zero-energy baseline. 
- **Deterministic Axis Scaling**: Extracts the global maximum and minimum relative energies across *all* frames to impose a fixed Y-axis bounding box. This guarantees consistent visualization for flipbook-style animation of the converging energy profiles.
- **Force Vector Extraction ($f_{max}$)**: Iterates through the intermediate atomic configurations (excluding the constrained boundary endpoints) to calculate the maximum Cartesian force on any atom, recording the global $f_{max}$ per macro step.
- **Structural Rendering**: Utilizes ASE's internal `plot_atoms` function, coupled with a fixed spatial rotation matrix (`'-45x,45y,10z'`), to generate standardized 3D perspective views of the molecules at each reaction coordinate.

## Usage
### Input
- `S1_NEB_Full_Path.traj`: A valid ASE trajectory file containing the full optimization history of the NEB calculation.

### Output
- `S1_NEB_Final_Optimized_Path.xyz`: A single `.xyz` file containing the latest converged MEP geometry for external animation tools (e.g., VMD, Ovito).
- `NEB_Individual_Frames/`: Directory containing standalone `.xyz` structure files for each individual image in the final path.
- `NEB_Step_Images/`: Directory containing side-by-side composite `.png` images of the 3D atomic structure and the highlighted point on the energy curve.
- `NEB_Macro_Step_Profiles/`: Directory containing sequential `.png` plots displaying the evolution of the energy barrier at each macro step, overlaid on previous historical iterations.
- `S1_NEB_Energy_Profile.png`: The final minimum energy path profile curve.
- `S1_NEB_Fmax_Evolution.png`: A line chart tracking the decay and stabilization of the maximum force throughout the macro steps.

## Example
Ensure the required trajectory file is located in the working directory, then execute the script via standard Python:
```bash
python 03_analyze_neb.py
```

## Conclusions
The outputs generated by this script comprehensively document the geometric and energetic convergence of the NEB search. The sequential macro step profiles validate whether the optimization process monotonically converged to the saddle point without numerical oscillations. The $f_{max}$ evolution chart quantitatively verifies that force tolerance criteria were successfully met. Ultimately, the extracted energy barrier provides the necessary thermodynamic and kinetic insights into the transition state of the modeled chemical reaction.
