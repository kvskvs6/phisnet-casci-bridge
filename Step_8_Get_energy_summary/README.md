# Molcas Energy Collector

## Overview
This script extracts electronic state energies (`ROOT_ENERGIES`) calculated by OpenMolcas. It pairs predicted energies generated by a computational model with ground-truth reference calculations and aggregates them into a structured CSV file (`energies.txt`) for downstream statistical analysis.

## Details of the Computation
The script utilizes `h5py` to parse hierarchical data format (`.rasscf.h5`) outputs from OpenMolcas. It dynamically constructs file paths and metadata by matching output directory names against a predefined structural pattern (`{basis}_{train}_{val}_{test}_{index}`). It implicitly performs deterministic data alignment by extracting the `ROOT_ENERGIES` array from the `Output/` directory (predictions) and directly mapping it to reference calculations located in the centralized `dataset/open/` archive. Only the lowest three electronic roots are automatically extracted and formatted into fixed-precision floats for numerical stability.

## Usage
- **Input:** 
  - Model predictions: `Output/{basis}_{train}_{val}_{test}_{index}/*.rasscf.h5`
  - Reference calculations: `../../dataset/open/open_g2m05_{index:04d}/{basis}/*.rasscf.h5`
- **Output:** A unified CSV-formatted dataset named `energies.txt` generated in the current execution directory.

## Example
Execute the script from the directory containing the `Output/` folder:
```bash
cd OpenMolcas_projects/20260610_Energy
python collect_energies.py
```

## Conclusions
The resulting `energies.txt` file yields a direct, root-by-root numerical comparison between predicted and reference multireference energies. This aggregated benchmark data is crucial for quantifying the model's predictive accuracy, evaluating its generalization error across different basis sets and training domain sizes, and informing further architectural refinements.
